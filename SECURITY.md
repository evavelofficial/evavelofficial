# Security Policy

Evavel Private Limited takes the security of its websites and products seriously, including evavel.com, evavel.link and the projects published under this GitHub account.

## Reporting a vulnerability

Please report security issues **privately** by email to **[hello@evavel.com](mailto:hello@evavel.com)** with the subject line `Security Report`.

Please include:

- The affected website, repository or URL
- A description of the issue and its possible impact
- Steps to reproduce (and a proof of concept, if available)

Please **do not** open a public GitHub issue, pull request or discussion for security problems.

## What to expect

- We aim to acknowledge reports within **3 business days**.
- We will keep you updated while we investigate and fix the issue.
- Once resolved, we are happy to credit you, if you wish.

## Guidelines

Please act in good faith: do not access or modify other people's data, do not disrupt our services, and give us reasonable time to fix an issue before any public disclosure.
